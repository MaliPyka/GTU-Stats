# GTU Stats Bot 📊



Телеграм-бот для студентов Грузинского технического университета (GTU). Бот автоматизирует проверку учебных результатов, парся данные с официального портала университета, и уведомляет пользователя об изменениях в оценках.



## 🌟 Основные функции

* **Автоматический парсинг**: Получение актуальных оценок с сайта GTU через браузер.

* **Уведомления**: Бот сообщает, когда в системе появляются новые баллы.

* **Безопасное хранение**: Пароли пользователей шифруются перед сохранением в базу данных.

* **Контейнеризация**: Полная изоляция приложения и базы данных для стабильной работы.



## 🛠 Технологический стек

* **Язык**: Python 3.10+

* **Библиотека бота**: [aiogram 3.x](https://docs.aiogram.dev/)

* **База данных**: PostgreSQL

* **ORM**: SQLAlchemy 2.0 (Async)

* **Парсинг**: Playwright (Chromium)

* **Планировщик задач**: APScheduler

* **Среда запуска**: Docker & Docker Compose







## 🚀 Быстрый старт



### 1. Подготовка окружения

Убедитесь, что у вас установлены **Docker** и **Docker Desktop**.



### 2. Клонирование репозитория

cmd
```
git clone [https://github.com/твой-логин/GTU-Stats.git](https://github.com/твой-логин/GTU-Stats.git)

cd GTU-Stats
```



3. Настройка переменных (файла .env)

Создайте файл .env в корневой папке и заполните его по примеру:



Фрагмент кода

BOT_TOKEN=1234567890:ABCdefGHIjklm...

DB_USER=user_name

DB_PASS=password

DB_NAME=db_name

DB_HOST=db

DB_PORT=5432



4. Запуск приложения

Выполните команду для сборки и запуска всех контейнеров:

cmd
```
docker-compose up --build
```


После завершения сборки бот автоматически подключится к базе данных и будет готов к работе.
